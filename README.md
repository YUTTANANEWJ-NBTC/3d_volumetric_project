# HoloVol 3D — Swept-Volume Volumetric Display (30×30×30 cm)

โปรเจกต์ต้นแบบและ Web Simulator สำหรับ **จอแสดงผลสามมิติเชิงปริมาตรจริง (True 3D Swept-Volume Volumetric Display)** ขนาดตู้โชว์ **30 × 30 × 30 เซนติเมตร** ที่สามารถมองเห็นมิติความลึกรอบทิศทาง 360° (รวมถึงด้านข้าง) โดยไม่ต้องสวมแว่นตา สำหรับนำไปจัดแสดงในงานอีเวนต์และนิทรรศการ (Exhibition & Brand Activation)

---

## จุดเด่นของระบบ (Key Features)
- **มุมมอง 360° รอบทิศทางจริง:** ต่างจากพัดลมโฮโลแกรม 2 มิติทั่วไป เพราะใช้ใบพัดเกลียว (Helical Rotor) กวาดรับแสงเลเซอร์ในแนวดิ่ง ทำให้เกิดจุดแสง (Voxel) ลอยอยู่ในปริมาตรจริง
- **16×16 Top-Down Laser Matrix (256 หัว):** จัดเรียงหัวเลเซอร์ด้านบนยิงลงมาด้วยระยะ Pitch 1.5 ซม. สร้างความละเอียดปริมาตร **4,096 Voxels (16×16×16)**
- **Interactive 3D Web Simulator (`index.html`):** จำลองการทำงานของใบพัด ความเร็วมอเตอร์ (RPM) สีเลเซอร์ และรูปทรง 3 มิติ เพื่อใช้พรีเซนต์ลูกค้าผ่านเว็บหรือ GitHub Pages ได้ทันที

---

## สเปกทางวิศวกรรม (30×30×30 cm Showcase Spec)
| รายการ | รายละเอียดสเปก |
| :--- | :--- |
| **ขนาดโครงสร้างตู้ (Enclosure)** | 30 × 30 × 30 ซม. (อะคริลิกใส/ดำกรองแสง) |
| **พื้นที่แสดงผลจริง (Active Volume)** | เส้นผ่านศูนย์กลางใบพัด 24 ซม. × ความสูงเกลียว 20 ซม. |
| **จำนวนหัวเลเซอร์ (Emitter Array)** | 16 × 16 = 256 หัว (ระยะห่างระหว่างหัว 1.5 ซม.) |
| **ระบบขับสัญญาณ (Laser Drivers)** | 32× Shift Register (TPIC6B595) ผ่านบัส SPI 10 MHz |
| **ไมโครคอนโทรลเลอร์ (Controller)** | ESP32-S3 / Teensy 4.1 |
| **มอเตอร์และเซนเซอร์ซิงค์รอบหมุน** | BLDC Motor (1,800 RPM / 30 Hz) + Hall Effect Zero-Crossing Sensor |
